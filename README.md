# Jarvis – Android-App

Die Handy-Version von Jarvis (goldene Kugel, Live-Gespräch mit dem Cloud-Jarvis, später PC- und Handy-Steuerung).

**Installieren:** Auf dem Handy die neueste Version öffnen:
https://github.com/sky3nb-prog/jarvis-android/releases/download/neueste/Jarvis.apk

Jede Änderung im Code baut automatisch eine neue APK (GitHub Actions).
