VECTOR

Dein Assistent für PC und Handy. In fünf Minuten eingerichtet.

Starten

1
Jarvis-Konto.exe doppelklicken.
Zeigt Windows „Der Computer wurde durch Windows geschützt“: Das kommt bei neuen Programmen ohne bezahltes Zertifikat. Auf „Weitere Informationen“ → „Trotzdem ausführen“ klicken. Das passiert nur beim ersten Mal.
2
Anmelden oder ein neues Konto anlegen – oder erst mal ohne. Mit Konto ist Vector auf jedem PC und Handy gleich; alles wird vorher mit deinem Passwort verschlüsselt.

Einrichten

3
KI-Schlüssel (kostenlos): auf console.groq.com/keys anmelden → „Create API Key“. Den Schlüssel (beginnt mit gsk_) in Vector unter Einstellungen → Allgemein → KI-Schlüssel einfügen. Ohne ihn kann Vector nur einfache Befehle.
4
Wohnort unter Einstellungen → Zuhause & Orte eintragen – für Wetter, Lage und Wege.
5
Reden: Sag „Vector“ und dann, was du willst – zum Beispiel „Vector, wie wird das Wetter?“ oder „Vector, öffne Discord“. Das Aktivierungswort kannst du in den Einstellungen ändern.

Handy dazu

6
Die Handy-App gibt es auf derselben Seite, von der du dieses Programm hast. Mit demselben Konto anmelden – fertig. PC und Handy finden sich dann von selbst.

Gut zu wissen

?
Updates kommen von selbst.
Hilfe: Frag einfach „Vector, wie richte ich dich ein?“
Entfernen: Windows-Einstellungen → Apps → Vector → Deinstallieren, oder in Vector unter Einstellungen → Vector-Konto → Selbstzerstörung. Dein Konto bleibt dabei.
Die Dateien, die Vector zum Arbeiten braucht, sind in diesem Ordner versteckt – bitte nicht verschieben.
